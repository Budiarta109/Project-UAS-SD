# 📊 Project UAS-SD — Graph DSS

## 📌 Deskripsi Project

Project ini merupakan aplikasi berbasis **Streamlit** yang digunakan untuk membangun dan memvisualisasikan sistem **Graph Decision Support System (DSS)**.

Aplikasi ini memanfaatkan beberapa library Python untuk pengolahan data, machine learning, serta visualisasi graph interaktif.

## ⚙️ Fitur Utama

* Visualisasi graph interaktif
* Analisis data menggunakan machine learning
* Interface berbasis web dengan Streamlit
* Pengolahan dataset menggunakan pandas & numpy
* Representasi jaringan menggunakan pyvis

## 📦 Instalasi

Clone repository ini terlebih dahulu:

```bash
git clone https://github.com/username/Project-UAS-SD.git
cd Project-UAS-SD
```

Install semua dependency:

```bash
pip install -r requirements.txt
```

Jika belum ada `requirements.txt`, bisa install manual:

```bash
pip install streamlit pandas numpy scikit-learn pyvis requests
```

---

## ▶️ Cara Menjalankan Program

Jalankan aplikasi Streamlit dengan perintah berikut:

```bash
streamlit run app.py
```
